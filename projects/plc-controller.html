Packaging Assembly Programmed Controller

Programmable Logic Controllers — Jan 2024 – May 2024

Programmed and validated an automated packaging line, catching an 11% error rate through testing before it could reach production.

Automated packaging system photo

Motivation

As part of a PLC programming course, a team of four engineering students was tasked with designing and building an automated packaging assembly system from scratch.

My contribution

  • Programmed an Allen-Bradley 1769-30ERM PLC using Studio 5000 to control automated system operation
  • Identified an 11% error rate through random batch testing, halted system operation, and implemented corrective improvements to reduce waste
  • Designed a small-scale circuit model for system fault detection and process optimization

Technical details

  • Studio 5000 / Allen-Bradley PLC programming
  • Random batch testing and error-rate analysis
  • Fault-detection circuit design
